Stardew Valley for AYN Thor — ZeroFrame LAB

Requirements:
- AYN Thor running ArmadaOS
- Original Steam Stardew Valley installed
- SMAPI 4.5.2 or later installed and configured as the Steam launch target

Install:
1. Extract the ZIP on the Thor.
2. Save and fully exit Stardew Valley.
3. Open a terminal in this folder.
4. Run: chmod +x install.sh uninstall.sh
5. Run: ./install.sh
6. Launch Stardew Valley normally from Steam.

The package contains no game files, saves, Steam credentials, or third-party mods.
See the GitHub README for controls, troubleshooting, known limitations, and source code.
